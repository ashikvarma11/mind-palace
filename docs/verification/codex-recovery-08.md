## Implemented behavior

- Indexing repairs complete sources for known Codex session IDs from the approved transcript folder. Unknown historical sessions need a separate review.
- History review shows the source, session/file count, date range and size. Confirmation uses a local UUID manifest, the consent revision, exact file metadata and a 15-minute expiry. Import pages check the file again after reading and before publishing. Configuration and history operations share the app-side lock. Files changed during the read are skipped without capture publication.
- Cleanup removes only acknowledged prefixes at least 30 days old when their complete bytes remain in the retained acknowledged source. It validates all references before deleting any file. Recent, divergent, unimported and complete acknowledged copies remain. If validation exceeds 128 MiB of reconstructed source, cleanup returns `deferred:true` and deletes nothing. This is an explicit capacity limit, not a complete large-inbox pruning guarantee.
- Ask searches known user/assistant conversation fields. Developer/system/tool records are excluded. Evidence offsets refer to unchanged raw source text. Ask syncs new captures before querying an open vault; it clears the previous answer while this operation runs. The answer is extractive text, not model synthesis.
- The reading view shows the latest 200 known Codex conversation messages. The complete source remains available. The evidence button opens the stored Session screen.
