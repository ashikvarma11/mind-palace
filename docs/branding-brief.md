# Approved branding brief

Name: Mind Palace. Direction: Workspace, approved after interactive review. Interface: system sans-serif typography, restrained neutral/blue surfaces, clear text statuses, top navigation, side-by-side work/focus panels with narrow-window stacking. Colors follow system light/dark appearance and use visible keyboard focus.

Image: preserve the supplied navy/cream/gold brain-shaped palace artwork exactly as the temporary logo, favicon/app-icon source and opening illustration. The original is a 1254-pixel square PNG, not an editable SVG. No newly generated/monochrome/simplified mark is approved; do not silently substitute one. Local 192-pixel display derivative preserves content.

Public redistribution license/provenance is unknown, so binaries remain ignored rather than falsely attaching the MIT code license. Local app retains the supplied image; source clones have a safe MP fallback. Native small-icon format/legibility checks are part of packaging, not already verified by a browser favicon.
